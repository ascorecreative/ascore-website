Three.js / React Three Fiber integration
GLB is Y-up and exported with seven individually named aperture blades, one core and a common parent. Preserve the scene transform hierarchy. Names in Three.js may have spaces/punctuation normalized by GLTFLoader; identify objects through the loaded scene traversal, not a guessed property name.

Animation
There are nine animation clips, one per animated object. All span frames 1–121 at 24 fps, i.e. five seconds. Activate every clip in a single THREE.AnimationMixer, set LoopOnce and clampWhenFinished, and scrub the mixer to progress * 5 seconds. Do not play only the first clip, which rotates only the parent. Pause the actions and set time explicitly, or set mixer time without running a competing delta-based clock. For GSAP ScrollTrigger, map normalized progress to the shared animation time; invalidate on resize. A custom articulation can instead drive the named blades, but avoid simultaneous baked animation and transform overrides.

Rendering
Use a studio environment (PMREM / RoomEnvironment or existing HDRI) so titanium has broad reflections. Asset intentionally includes no web lights/cameras/environment; adapt lighting to the actual page. Cyan and violet material bands complement the existing logo; preserve the page's ink, ivory and acid accents. Cap mobile DPR at 1.5, render on demand when static, and suspend off-screen. Disable scroll animation under prefers-reduced-motion and retain assembled pose. The geometry needs no Draco download/runtime.
