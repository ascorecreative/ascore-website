# Course storefront and disabled Nomod preparation

This release follows `344de884761c9d0c723cef483e41ae2a224ddfd5` on `codex/ascore-cloud-hero-portals`. Publish through the existing Git integration with `npm ci`, `npm run build`, and the existing Node entry `server/index.mjs`. No hosting control or File Manager access is required for Git publication. Hosting deployment must be independently checked after the push.

The course landing, both product pages, cart and guest checkout use a responsive layout with factual inclusions, readable pricing, grouped curricula, support and clear availability. Prices remain AED 50 each. Main homepage source, desktop design, mobile animations, portal and the optimized video remain unchanged.

Meta preview images are selected authorized raster excerpts of the latest private PDF, pages 10, 23 and 45. They are labelled as samples; page 45 is guidance, not a claimed real Pixel capture. The 54-page PDF contains 17 genuine captures. The AI sample is a clearly labelled, verified text excerpt from page 10 of the 42-page course: consumer-local Library materialization of the complete AI file was unavailable. No full paid PDF is included in Git or served by the storefront. Native preview dialogs support Escape, arrow keys, focus restoration and reduced motion. The mobile product action appears within the first 844px screen; the later sticky action hides around the cart and preview dialog.

Design research: [Baymard checkout research](https://baymard.com/research/checkout-usability), [Nielsen Norman Group information scent](https://www.nngroup.com/articles/information-scent/), [W3C target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html). Controls aim for 44–48px, avoid unnecessary guest fields, and preserve email and cart state. No fabricated ratings, student counts, results, scarcity or gateway assurances are added.

Nomod checkout and signature verification are prepared behind disabled gates, with mock tests only. Server-priced AED totals, durable checkout references, strict return verification, raw-body Svix signatures, event deduplication, private download authorization and single delivery claims are implemented. Redirects and authorisation do not establish payment. Unknown provider or email outcomes require review rather than automatic repetition. Paid delivery and production provider calls cannot activate from runtime keys alone: the application hardcodes `contractVerified:false` until real Hosted Checkout correlation and captured-charge evidence are independently reviewed. Optional payment tables have a separate, explicit ownership-checked setup command; normal startup performs no migrations.

See [course runtime setup](../courses-runtime-setup.md) for the independent orders mailbox fields and remaining private setup. No emails, Nomod API requests, charges, credentials, production migrations or private PDF installation occurred during this release.

Validation: all 50 backend tests passed, lint completed with the three pre-existing warnings, and the normal API-mode production build passed. Isolated headless Chromium checked all four routes at 320, 390, 768 and 1440px with no horizontal overflow or runtime errors. Real preview decoding, keyboard navigation/focus, cart deduplication/persistence, retained email, review invalidation, disabled payment/delivery controls, untrusted return URLs, AI sample tabs and prerendered no-JavaScript content passed. Browser checks issued no POST requests. Homepage HTML and both existing videos are byte-for-byte unchanged; no main website or portal bundle changed. Seven unrelated dirty files in the shared checkout were preserved. Selected preview hashes are recorded in `2026-10-06-preview-evidence.json`.
