# Owner Nomod test and GA4 dashboard reporting

Home and Analytics now include GA4 reports, with Today, Yesterday, 7 days and 30 days controls, active users, sessions, page views and the top 10 source/medium combinations by sessions. Realtime is explicitly the entire connected property's active users in the last 30 minutes; historical reports filter hostname ascore.ae. Periods follow the GA4 property's timezone, include today in 7/30-day ranges, and display provider fetch timestamps. Google thresholding and `(other)` aggregation are surfaced. Totals come from their own aggregate report, not a sum of distinct users across sources.

The authenticated agency-only GET `/api/analytics/ga4?range=today` calls only Google's fixed token endpoint and `runReport`/`runRealtimeReport` endpoints for the server-configured property. RSA service-account JWTs request only `https://www.googleapis.com/auth/analytics.readonly`. Credentials and tokens remain server-side; supplied credential token_uri is ignored. No Measurement Protocol events, Google account changes, arbitrary metrics, client-supplied credentials or guessed counts. Valid empty provider reports show zero; absent connection shows setup required; authentication, quota, invalid response and network errors show unavailable. Responses are bounded to 256 KB, requests time out, token/report flights coalesce, realtime caches 30 seconds and historical reports cache two minutes. The dashboard refreshes each minute while visible, with request cancellation when changing range or leaving the view.

## Minimal GA4 connection handoff

1. In Google Analytics, select the Ascore property, open Admin → Property settings/details and copy the numeric **Property ID**. `G-MX800C01N9` is a stream measurement ID and cannot authorize reporting.
2. In the owner's Google Cloud project, enable **Google Analytics Data API**, create a dedicated reporting service account and its JSON key. No Analytics Editor/Admin role or domain-wide delegation is needed. In GA4 Admin → Property access management, add that service account's `client_email` with **Viewer** access to this property only.
3. In the private Node hosting environment, save `ASCORE_GA4_PROPERTY_ID=<numeric ID>` and `ASCORE_GA4_SERVICE_ACCOUNT_JSON=<the complete JSON credential>` and restart. Keep the key out of chat, Git and all frontend/VITE variables. The Home/Analytics panel performs the read and displays any concrete access error.

No actual property ID or reporting credential was supplied to this agent, so actual Google report receipt is pending this owner connection. The existing consent tag remains unchanged and Enhanced Measurement remains off. Its current omission of campaign queries/referrers limits source attribution; the dashboard labels this limitation and displays what Google actually records.

As aswinfrn, select **Create one AED 49.99 test checkout** and confirm the finite live-creation scope. The server posts one Meta item, amount 49.99, AED, zero discount and private portal return URLs to `https://api.nomod.com/v1/checkout`. It omits customer/email and recurring billing fields.
